# ALAMIR SECURITY — сайт охранной компании (Алматы)

Прототип сайта для согласования с заказчиком. Отвечай пользователю по-русски.

## Как устроен проект

- Весь сайт — один файл `index.html`: HTML, CSS и JavaScript внутри, картинки встроены как data URI. Сборки нет.
- Одностраничное приложение с роутингом по `location.hash` (`#home`, `#map`, `#about`, `#contacts`, `#privacy`, страницы услуг по их id). Всё рисует функция `render()` через объект `VIEWS`.
- Два языка: русский и казахский. Строки интерфейса — в объекте `UI`, функция `t('ключ')`; данные с переводом — объекты `{ru, kk}`, функция `L(obj)`. Любой новый текст добавляй сразу на оба языка.
- Проверка локально: `python3 -m http.server 8000` в корне репозитория, затем http://localhost:8000. 3D требует интернета: Three.js r147 грузится с cdn.jsdelivr.net.

## Карта охраны: выбор источника

1. `MAP_CFG.dgisKey` задан → MapGL JS API 2ГИС (реальные улицы).
2. Ключа нет или 2ГИС не загрузился → 3D-схема на Three.js (условная сетка кварталов, горы на юге).
3. Нет WebGL, Three.js не загрузился или 3D упал во время работы → обычная 2D-карта (SVG) с теми же объектами.

Стартовый вид 2ГИС взят из ссылки заказчика: центр `[76.933904, 43.269714]`, масштаб 10.7.

## Правила, которые нельзя нарушать

- Данные 2ГИС — только через официальный MapGL JS API с ключом. Не копировать карты, тайлы и геометрию с сайта 2gis.kz и не обходить ограничения. Атрибуцию 2ГИС на карте не перекрывать.
- Все объекты на карте и движение машин — демонстрационные, это должно быть подписано. Реальные адреса клиентов и посты охраны не публиковать без письменного разрешения.
- В режиме 2ГИС демо-маркер встанет на реальное здание и может выглядеть как «наш клиент». Решение заказчика ещё не принято: реальные объекты с согласием, маркеры на районы или без объектов.
- Не выдумывать факты о компании: тексты — образцы, данные в пунктирных рамках — заглушки.
- Ключ MapGL виден в коде страницы — это нормально, но его нужно ограничить доменом в кабинете 2ГИС.

## Что проверено, а что нет

- Проверено автотестами (Playwright, Three.js был заменён заглушкой): переходы между страницами, смена языка, 2D-карта целиком, логика HUD, карточки, фильтры, переход к форме, переключение на 2D при сбое 3D, движение машин по дорогам.
- Не видели глазами: саму 3D-графику главной и карты (в прошлой среде не было интернета). Первым делом открой сайт в браузере и проверь 3D на компьютере и телефоне.
- Режим 2ГИС написан по документации, но не запускался: нужен ключ.
